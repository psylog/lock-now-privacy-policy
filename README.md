# Privacy Policy for Lock Now

**Effective date:** October 2, 2026

## Overview
Lock Now is built as a free utility application. This service is provided at no cost and is intended for use as is.

## Information Collection and Use
Lock Now does **NOT** collect, store, or transmit any personally identifiable information, usage data, or analytics. All operations performed by the application remain strictly local to your device.

## Permissions Used
The application may request specific system permissions solely to fulfill its core functionality of locking the screen:
* **Accessibility Services / Device Admin:** Used exclusively to initiate screen lock upon user action.
* These permissions are **never** used to harvest data or monitor user activity.
